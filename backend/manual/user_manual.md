# 面试模拟 Agent - Web版 操作手册

---

## 一、系统概览

**Q1: 这个系统是什么？**
A1: 这是一个基于大语言模型的智能面试模拟系统。用户上传简历后，系统可以：
- 自动分析简历中的意向岗位和城市
- 通过Agent担任面试官进行模拟面试
- 提供职业指导和技术辅导
- 支持简历管理（上传、激活、删除）

**Q2: 我需要使用什么浏览器？**
A2: 推荐使用 Chrome、Edge 或 Firefox 等现代浏览器，确保 JavaScript 和 WebSocket 功能正常。

---

## 二、注册与登录

**Q3: 如何注册新用户？**
A3: 点击登录框中的「立即注册」链接，填写以下信息：
- 用户名（5-50个字符）
- 有效邮箱地址
- 密码（至少8位）
提交后自动登录并跳转到主界面。

**Q4: 如何登录已有账户？**
A4: 在登录界面输入用户名和密码，点击「登录」按钮。系统将验证凭证并返回用户ID。

**Q5: 登录失败可能的原因有哪些？**
A5: 常见原因包括：
- 用户名或密码错误（连续5次失败会暂时锁定账户）
- 账户已被管理员禁用
- 网络连接问题
- 浏览器缓存导致会话异常

**Q6: 如何修改密码？**
A6: 登录后点击右上角「用户管理」→「修改密码」，输入：
- 旧密码
- 新密码（至少8位）
点击保存，修改成功后需重新登录。

**Q7: 如何修改邮箱？**
A7: 登录后点击右上角「用户管理」→「修改邮箱」，输入新邮箱地址并保存。新邮箱需未被他人注册。

**Q8: 如何登出？**
A8: 点击右上角「用户管理」→「退出」，或关闭浏览器标签页。登出后本地存储的 user_id 会被清除。

## 三、简历管理

**Q9: 简历支持哪些格式？**
A9: 仅支持 **.pdf** 和 **.docx** 两种格式。

**Q10: 文件有什么限制？**
A10: 单文件大小不能超过 **10MB**，每个用户最多上传 **3份** 简历（包含已删除和未激活的）。

**Q11: 如何上传简历？**
A11: 登录后点击左侧面板的「上传简历」按钮，选择本地文件（.pdf 或 .docx），系统自动解析文本并保存。上传成功后该简历自动激活，之前的其他简历会取消激活状态。

**Q12: 上传时需要注意什么？**
A12: 重要提示：
- 扫描件（图片型 PDF）无法提取文本，请使用文本型 PDF 或 Word 文档
- 文件不能为空或损坏
- 上传过程需要一定时间，请耐心等待

**Q13: 如何查看和管理已上传的简历？**
A13: 点击「管理简历」按钮，会显示所有已上传的简历列表，包括：
- 文件名
- 上传时间
- 激活状态（使用中/未使用中）
可对未激活简历进行「激活」操作，或对任意简历进行「删除」操作。

**Q14: 激活简历是什么意思？**
A14: 激活简历意味着选择该简历作为当前面试使用的简历系统只允许一份简历同时处于激活状态。激活新简历会自动取消之前所有简历的激活状态。

**Q15: 删除简历会怎样？**
A15: 删除是逻辑删除（标记为不可用），同时会删除原始文件。删除后无法恢复，请谨慎操作。

## 四、面试模拟功能

**Q16: 如何开始面试？**
A16: 确保已上传并激活一份简历后，在聊天输入框中输入 `/start` 并按回车，或者点击左侧面板的「开始面试」按钮。系统会自动：
1. 分析简历中的意向岗位
2. 获取岗位JD要求
3. Agent开始进行模拟面试

**Q17: 面试流程是怎样的？**
A17: 面试流程如下：
- Agent首先请候选人做1-2分钟的自我介绍
- 基于简历中的项目经验和技术栈提问
- 结合JD技能要求考察匹配度
- 从基础问题逐步深入到技术问题
- 最后总结反馈并结束面试

**Q18: 面试过程中有什么限制？**
A18: 面试过程中需要注意：
- 一次只问一个问题，不要一次性问多个
- 根据回答动态调整难度
- Agent会在必要时提供建设性反馈
- 候选人可随时主动提出结束面试

**Q19: 如何结束当前面试？**
A19: 在聊天框输入 `/end` 或点击「结束面试」按钮，面试会话将被终止。之后可以输入 `/start` 重新开始面试。

**Q20: 面试时Agent会给什么类型的反馈？**
A20: 根据回答质量，反馈分为三类：
- **优秀**：给予肯定，如"回答得很好，理解很到位"
- **一般**：鼓励性反馈，如"基本正确，可以补充XXX方面"
- **较差**：给出建议，如"我觉得你可以这样回答：XXX，这样更能体现你的技术深度"

**Q21: 我可以查看面试历史吗？**
A21: 可以，输入 `/history` 可以查看当前会话的对话历史（最多显示最近10条）。如果对话已被清空，则显示"暂无对话历史"。

**Q22: 如何清空对话历史？**
A22: 输入 `/clear` 可以清空当前会话的对话历史，但不会删除已上传的简历或结束面试会话。

## 五、向量库与JD查询

**Q23: 什么是向量库？**
A23: 向量库用于存储职位描述（JD）数据，通过语义搜索快速匹配相关岗位信息。系统内置了常用岗位的JD数据。

**Q24: 如何查询向量库？**
A24: 使用 `/vector 关键词` 命令，例如 `/vector python`，系统会返回向量库中包含该关键词的JD记录数量。

**Q25: 我可以搜索特定的技术吗？**
A25: 可以，在 `/vector` 后跟任意技术关键词，如 `/vector Java`、`/vector 数据库`、`/vector 前端` 等，系统将搜索匹配的JD。

## 六、系统命令速查

| 命令 | 说明 |
|------|------|
| `/start` | 开始面试流程，系统自动加载简历并分析岗位 |
| `/end` | 结束当前面试会话 |
| `/resume` | 查看当前激活简历的内容信息 |
| `/vector 关键词` | 搜索向量库中匹配关键词的JD数量 |
| `/history` | 查看当前对话历史 |
| `/clear` | 清空对话历史 |

## 七、常见问题与故障排除

**Q26: 点击开始面试但没有任何反应？**
A26: 请检查：
1. 是否已登录并拥有有效的 user_id
2. 是否已上传并激活了简历
3. 网络连接是否正常
4. 浏览器控制台是否有错误信息

**Q27: 上传简历提示"无法提取文本内容"？**
A27: 可能原因：
- 文件是扫描件（图片型PDF），建议先用 OCR 工具转换
- 文件损坏或为空
- 文件格式不支持（请确认是 .pdf 或 .docx）
重新上传一个文本清晰的文件即可。

**Q28: 面试开始后Agent没有按预期提问？**
A28: 请确认：
1. 简历中的关键信息（技术栈、项目经验等）是否清晰可提取
2. 是否有语法错误或乱码
3. 检查对话历史是否有系统错误提示
如有问题可重新上传简历并尝试。

**Q29: 如何获取帮助？**
A29: 点击右上角「帮助文档」按钮查看完整操作说明，或输入 `/help`（如系统支持）。本手册涵盖所有常用功能。

**Q30: 面试结束后可以重新面试吗？**
A30: 可以。面试结束后（输入 `/end`），再次输入 `/start` 即可开始新的面试会话，系统会重新加载简历并进入面试流程。
